# SnakeGame
Snake is a classic arcade game, originally programmed in C. For this reason, I’ve chosen it as the subject for learning how to program in C++. I intend to document the entire process, which will serve to prove to myself that I don’t need AI to build small-to-medium-sized projects from scratch.
The goal is for this to be the first of many programs, with each one increasing in difficulty—challenging both my creativity and my intelligence.
